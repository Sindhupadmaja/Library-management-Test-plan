# Test Evidence

This folder is reserved for screenshots or screen recordings from manual execution.

Recommended evidence to capture:

1. Successful login
2. Invalid login validation
3. Book search with matching result
4. Book search with no result
5. Borrowing an available book
6. Returning a borrowed book
7. Defect reproduction

For GitHub, save screenshots with descriptive names such as:

- `TC-001-valid-login.png`
- `TC-002-invalid-login.png`
- `TC-005-book-search.png`
- `TC-008-borrow-book.png`
- `TC-011-return-book.png`

Do not place passwords, personal information, or real credentials in screenshots.
